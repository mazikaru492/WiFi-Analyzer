【Wi-Fi Environment Analyzer】
～あなたの周りのWi-Fi、見えますか？～

■ これは何？
目に見えないWi-Fiの電波をキャッチして、
「どのくらい混雑しているか？」
「どのチャンネルが空いているか？」
をグラフで分かりやすく表示するツールです。

■ 使い方（とっても簡単！）

1. `dist` フォルダを開いて `WiFiAnalyzer.exe` を起動します。
   （黒い画面が一瞬出ますが、すぐにアプリが立ち上がります）

2. 「手動スキャン」ボタンを押します。
   → 今飛んでいるWi-Fiがグラフになって現れます！

■ 画面の見方
・山の高さ：電波の強さ（高いほど強い！）
・赤い山　：今あなたが使っているWi-Fi
・山の重なり：電波がぶつかっている場所（混雑中！）

■ ポイント
山と山が重なっていない「空いている場所」を見つけるのが、
快適なWi-Fi環境を作るコツです。

ぜひ、あなたの周りの電波状況をチェックしてみてください！
