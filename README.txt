【作品タイトル】
Wi-Fi Environment Analyzer (Wi-Fi可視化ツール)

【サブタイトル】
無線LANの混雑状況をスペクトラム表示し、最適なチャンネル選定を支援するツール

【概要（1〜2行）】
Pythonを用いて周囲のWi-Fi APをスキャンし、SSIDごとの電波強度(RSSI)とチャンネルの分布を可視化するアプリケーションです。
電波干渉の状況をグラフィカルに把握することで、通信環境の改善に役立てることができます。

【実行方法（1〜3行）】
1. 依存ライブラリのインストール： pip install pywifi comtypes pandas matplotlib
2. アプリケーションの起動： python wifi_test.py
3. GUI上の「手動スキャン」ボタン押下にて取得処理を開始

【必要ファイル】
wifi_test.py

【開発環境】
OS：Windows 11
開発ツール：Antigravity
Python：3.12

【使用ライブラリ】
tkinter (標準): GUI構築
threading (標準): 非同期処理（スキャン時のフリーズ回避）
pywifi: Wi-Fiインターフェース制御、スキャン実行
pandas: 取得データの構造化、フィルタリング処理
matplotlib: スペクトラムグラフの描画、インタラクティブ操作

【実装した機能（箇条書き）】
・Wi-Fiインターフェースの制御および周辺APのSSID、BSSID、RSSI、チャンネル情報の取得
・matplotlibを用いた2.4GHz/5GHz帯域別スペクトラムグラフの描画
・現在接続中のネットワーク情報の取得とグラフ上でのハイライト表示（赤色強調）
・定期的なバックグラウンドスキャンによるリアルタイムモニタリング機能
・グラフ上のデータポイント（ピーク）に対するクリックイベント処理と詳細ダイアログ表示
・データキャッシュ機構による表示の安定化（瞬断時のグラフ消失防止）

【工夫した点（最大3つ）】
1. 非同期処理によるUX向上: Wi-Fiスキャンはブロッキング処理となるため、メインスレッドとは別のスレッドで実行させることで、スキャン中もGUIがフリーズしないように実装しました。
2. 視認性を意識したグラフ描画: チャンネルごとの混雑状況が直感的に分かるよう、電波強度を正規分布曲線で近似して描画し、物理的な電波の重なりを表現しました。また、SSIDラベルが密集した場合に重ならないよう、Y座標を動的に調整するアルゴリズムを導入しました。
3. 接続情報の動的取得: `netsh` コマンド等の出力を解析し、現在接続しているAPを自動判別してグラフ上で強調表示することで、自分への影響が一目で分かるようにしました。

【既知の不具合】
・Wi-Fiアダプターの仕様により、スキャン完了まで数秒のラグが発生する場合があります。
・一部の環境（特定のNICドライバ）では `pywifi` がインターフェースを認識しない可能性があります。

【制作中に大変だったこと】
・GUI（tkinter）とグラフ描画（matplotlib）の連携において、更新頻度を上げすぎると描画負荷で動作が重くなるため、更新間隔やキャッシュの扱いを調整するのに苦労しました。

【試したこと】
