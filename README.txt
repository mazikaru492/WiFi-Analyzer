【作品タイトル】
Wi-Fi 環境分析ツール
【サブタイトル】
周囲のWi-Fi電波をスペクトラムグラフで可視化

【概要（1〜2行）】
この作品は、周囲のWi-Fiネットワークをスキャンし、2.4GHz/5GHz帯のチャネル別電波強度をスペクトラムグラフで可視化するプログラムです。

【実行方法（1〜3行）】
python wifi_test.py

【必要ファイル】
なし

【開発環境】
OS：Windows
開発ツール：Antigravity
Python：3.11

【使用ライブラリ】
tkinter, pywifi, comtypes, pandas, matplotlib, socket, subprocess, math, sys, threading, time
※外部ライブラリ：pip install pywifi comtypes pandas matplotlib

【実装した機能（箇条書き）】
・周囲のWi-Fiネットワークを手動スキャンする機能
・2.4GHz/5GHz帯を切り替えてスペクトラムグラフで可視化する機能
・自動更新モードでリアルタイムに電波状況を監視する機能
・現在接続中のSSIDを赤色で強調表示する機能
・Wi-Fiアダプターを選択して切り替える機能
・グラフ上のネットワークをクリックして詳細情報を表示する機能
・10秒間のキャッシュでデータを保持し安定した表示を実現する機能

【工夫した点（最大3つ）】
1. スマートラベル配置機能により、チャネルが近いネットワーク同士のラベル重なりを自動回避している
2. データ保持（Persistence）機能で、スキャン間隔中もデータをキャッシュし、安定したグラフ表示を実現している
3. 周波数からチャネルへの変換ロジックで、誤差を許容した最近傍マッピングを実装し精度を向上させている
