# Wi-Fi可視化ツール

**作った人**: 古家悠貴（25a31e0014）

---

## これなに？

周りに飛んでるWi-Fiの電波をスキャンして、**グラフで見える化**するアプリです！

「なんかWi-Fi遅いな～」って思ったこと、ありませんか？
実はそれ、周りの電波と干渉してるのが原因かも。
このツールを使えば、どのチャンネルが混んでるか一目でわかります！

---

## 何ができるの？

| できること        | 説明                                       |
| ----------------- | ------------------------------------------ |
| Wi-Fiスキャン     | ボタン押すだけで周りのWi-Fiを全部見れる    |
| グラフ表示        | チャンネルごとの電波の強さがグラフでわかる |
| 自動更新          | リアルタイムで電波状況を監視できる         |
| 2.4GHz / 5GHz対応 | 両方の周波数帯を見れる                     |
| 接続中を強調      | 今つながってるWi-Fiは赤色で表示            |

---

## 動かすのに必要なもの

- **Windows PC**
- **Python 3.8以上**

---

## インストール方法

コマンドプロンプトかPowerShellで以下を実行してね：

```bash
pip install pywifi comtypes pandas matplotlib
```

---

## 使い方

### 起動

```bash
python wifi_test.py
```

### 操作方法

1. アプリが開いたら「**手動スキャン**」をクリック
2. グラフにWi-Fiの電波状況が表示される
3. 「**自動更新: OFF**」をクリックするとリアルタイム更新が始まる
4. 「**2.4GHz**」「**5GHz**」で周波数帯を切り替えられる
5. グラフをクリックするとそのWi-Fiの詳細が見れる

## 電波の強さの見方

| 強度 (dBm) | 状態         |
| ---------- | ------------ |
| -50以上    | めっちゃ良い |
| -60～-50   | 良い         |
| -70～-60   | 普通         |
| -80～-70   | ちょっと弱い |
| -80未満    | かなり弱い   |
