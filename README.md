# 📡 Wi-Fi Environment Analyzer

Wi-Fiスキャン＆チャネル分析ツール - 周囲のWi-Fi電波状況をリアルタイムで可視化するデスクトップアプリケーション

![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)
![Platform](https://img.shields.io/badge/Platform-Windows-lightgrey.svg)
![License](https://img.shields.io/badge/License-MIT-green.svg)

---

## 📖 概要

周囲のWi-Fiアクセスポイントの情報（SSID、電波強度、使用チャネル）をリアルタイムで取得し、チャネルごとの混雑状況をスペクトラムグラフで可視化するデスクトップアプリケーションです。

### ✨ 主な機能

| 機能 | 説明 |
|------|------|
| 🔍 **リアルタイムスキャン** | 周囲のWi-Fi情報を即座に取得・分析 |
| 📊 **スペクトラムグラフ表示** | チャネル別の電波強度を視覚的に表示 |
| 🔄 **自動更新モード** | 数秒ごとにグラフを自動リフレッシュ |
| 📶 **2.4GHz / 5GHz 切り替え** | 両周波数帯の分析に対応 |
| 🔴 **接続中SSID強調表示** | 現在接続中のネットワークを赤色で表示 |
| 💾 **データ保持機能** | 10秒間のキャッシュで安定した表示 |
| 🎯 **ネットワーク詳細表示** | グラフをクリックして詳細情報を確認 |

---

## 🖼️ スクリーンショット

### 2.4GHz帯スペクトラム
ボタン1つで周囲のWi-Fiをスキャン。どのチャネルが混雑しているか一目で確認できる可視化画面

### 5GHz帯スペクトラム
高速な5GHz帯の状況を表示。オフィス等で干渉の少ない快適な通信環境を選ぶ判断材料になります

### リアルタイム自動更新
電波状況を常時監視する自動更新機能。時間帯による混雑の変化をリアルタイムで把握し安定通信を支援

## 💻 使い方

### アプリケーションの起動

```bash
python wifi_test.py
```

### 基本操作

1. **アダプターの選択** - 複数のWi-Fiアダプターがある場合、ドロップダウンから選択
2. **手動スキャン** - 「手動スキャン」ボタンをクリックして周囲のWi-Fiをスキャン
3. **自動更新** - 「自動更新: OFF」ボタンをクリックしてリアルタイム監視を開始
4. **周波数帯切り替え** - ラジオボタンで2.4GHz / 5GHzを切り替え
5. **詳細表示** - グラフ上のネットワークをクリックして詳細情報を確認

## 🛠️ 技術仕様

### 使用ライブラリ

- **tkinter** - GUIフレームワーク
- **pywifi** - Wi-Fiインターフェース操作
- **pandas** - データ処理・分析
- **matplotlib** - グラフ描画
- **threading** - マルチスレッド処理

### 主要クラス

```python
class WifiAnalyzerApp:
    """
    Wi-Fi環境分析アプリケーションのメインクラス

    主要メソッド:
    - init_wifi()              # Wi-Fiインターフェースの初期化
    - start_manual_scan()      # 手動スキャン開始
    - toggle_auto_scan()       # 自動更新のON/OFF切り替え
    - process_results()        # スキャン結果の処理
    - update_graph()           # グラフの更新
    - show_network_info()      # ネットワーク詳細情報の表示
    """
```

### データキャッシュ機能

```python
# キャッシュ構造
wifi_cache = {
    "SSID_チャンネル": {
        "signal": -45,        # 信号強度 (dBm)
        "last_seen": 時刻,    # 最終検出時刻
        "ssid": "ネットワーク名",
        "channel": 6,         # チャンネル番号
        "band": "2.4GHz"      # 周波数帯
    }
}
cache_ttl = 10  # データ保持期間（秒）
```

## 📊 信号品質の判定基準

| 信号強度 (dBm) | 品質 |
|---------------|------|
| -50 以上 | 優秀 (Excellent) |
| -60 〜 -50 | 良好 (Good) |
| -70 〜 -60 | 普通 (Fair) |
| -80 〜 -70 | 弱い (Weak) |
| -80 未満 | 非常に弱い (Very Weak) |

## 🔧 トラブルシューティング

### Wi-Fiアダプターが検出されない

- Wi-Fiが有効になっているか確認してください
- 機内モードがOFFになっているか確認してください
- 外部Wi-Fiアダプターを使用している場合、正しく接続されているか確認してください

### スキャン結果が表示されない

- 管理者権限で実行してみてください
- アダプターを切り替えてみてください
- 自動更新モードをONにして数秒待ってみてください
