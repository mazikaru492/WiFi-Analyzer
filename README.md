# Wi-Fi Environment Analyzer

## Wi-Fi電波を「見える化」するツール

**作成者**: 古家悠貴（25a31e0014）

---

## 📌 概要

周りに飛んでいるWi-Fi電波をスキャンして、**直感的なスペクトラムグラフで「見える化」**するデスクトップアプリケーションです。  
混雑しているチャンネルを一目で特定し、快適なWi-Fi環境を構築するための「電波の地図」を提供します。

**こんな場面・人におすすめ：**
- 📶 「なんだかWi-Fiが遅い・頻繁に切れる」と困っている
- 🔍 どのチャンネルが空いているか視覚的に確認したい
- ⚡ 自分のWi-Fiと近隣のWi-Fiが干渉（重なり）していないか調べたい
- 🎛️ 信号強度の強いWi-Fiだけをフィルタリングしてクリアに観察したい

---

## ✨ 主な機能と特徴

1. **直感的なスペクトラムグラフ描画**
   - 2.4GHz帯（1〜14 Ch）および 5GHz帯（36〜177 Ch）の周波数帯に対応。
   - 今自分が接続しているWi-Fiを**赤色の山**でハイライト表示し、迷子になりません。
2. **信号強度（RSSI）フィルター機能** 🆕
   - スライダー操作（-100 dBm ～ -20 dBm）で弱い電波を非表示にし、必要なWi-Fiだけをピックアップ。
   - フィルター適用後の表示件数をリアルタイム表示。
3. **インタラクティブな詳細表示＆複数選択メニュー** 🆕
   - グラフ上のWi-Fi波形をクリックすると、詳細情報（SSID, BSSID, チャンネル, 電波強度, 品質評価）を表示。
   - 電波が重なっている場所をクリックした場合は、ポップアップメニューで目的のWi-Fiを正確に選択可能。
4. **自動更新（リアルタイム監視）モード**
   - 手動スキャンに加え、一定間隔で自動的に電波状況を再描画。電波強度の変動をリアルタイムに確認できます。
5. **マルチアダプター対応＆文字化け防止機構**
   - PCに接続されている複数のWi-Fiアダプターをドロップダウンで即座に切替可能。
   - 日本語SSID（UTF-8, CP932/Shift-JIS）の自動デコードに対応し、文字化けを防止。

## 🚀 起動方法（2つのやり方）

### 方法1：EXEファイルで起動（推奨・Python不要）

1. `dist` フォルダを開きます。
2. `WiFiAnalyzer.exe` をダブルクリックして起動します。

> ⚠️ **注意**: 初回起動時にWindows Defenderのセキュリティ保護警告が表示された場合は、

## 📖 基本的な使い方

### 1. 画面構成

```
┌────────────────────────────────────────────────────────────────────────┐
│ 現在の接続: SSID [接続中のWi-Fi名] / IP [xxx.xxx.xxx.xxx]              │
├────────────────────────────────────────────────────────────────────────┤
│ アダプター: [WLAN▼] [手動スキャン] [自動更新:OFF]  ○ 2.4GHz  ○ 5GHz    │
├────────────────────────────────────────────────────────────────────────┤
│ 信号強度フィルター: [─────●───────] -100 dBm 以上を表示 [リセット]   │
├────────────────────────────────────────────────────────────────────────┤
│                                                                        │
│                ～ Wi-Fi スペクトラムグラフ ～                           │
│                                                                        │
├────────────────────────────────────────────────────────────────────────┤
│ 検出ログ: スキャン結果やステータスがリアルタイムに表示されます         │
└────────────────────────────────────────────────────────────────────────┘
```

### 2. スキャンと観察

1. **「手動スキャン」ボタン**をクリックすると、周囲のWi-Fi電波を取得してグラフにプロットします。
2. **自動更新**をONにすると、リアルタイム監視モードに切り替わります。
3. **ラジオボタン**で「2.4GHz帯」と「5GHz帯」をいつでも簡単に表示切り替えできます。

### 3. 信号強度フィルターの活用

1. 画面上部の**信号強度スライダー**を動かすことで、例えば `-70 dBm` 以上の強い電波のみに絞り込むことができます。
2. 混雑した場所でノイズとなる弱い電波を隠し、自社・自宅の主要なアクセスポイントを分析しやすくなります。
3. **「リセット」ボタン**を押すと、一発で初期状態（-100 dBm 以上＝全表示）に戻ります。

### 4. Wi-Fi詳細の確認

- グラフ上の山をクリックすると詳細ダイアログが表示されます。
- 複数の山が重なっている箇所をクリックした場合は、**ポップアップ選択メニュー**が表示され、確認したいSSIDを選択できます。

## 📊 電波強度の読み方と電波改善のコツ

### 電波強度（RSSI）の目安

| 信号強度 (dBm) | 品質評価 | 状態と推奨アクション |
| :---: | :---: | :--- |
| **-50 以上** | 🟢 **優秀 (Excellent)** | 非常に強力。動画ストリーミングやオンラインゲームに最適 |
| **-60 ～ -50** | 🔵 **良好 (Good)** | 安定した通信が可能 |
| **-70 ～ -60** | 🟡 **普通 (Fair)** | 通常のWeb閲覧は問題ないが、時間帯によって少し遅く感じる場合あり |
| **-80 ～ -70** | 🟠 **弱い (Weak)** | 不安定になりやすい。ルーターに近づくかチャンネル変更を推奨 |
| **-80 未満** | 🔴 **非常に弱い (Poor)** | パケットロスや切断が頻発するレベル |

> 💡 **ポイント**: dBm値はマイナス値のため、**0に近いほど強力**です（例: `-50 dBm` は `-80 dBm` より強い）。

---

### チャンネル干渉と最適化のポイント

```
【理想的な状態（山が離れている）】
     ▲           ▲
    / \         / \
   /   \       /   \
──┴─────┴─────┴─────┴──
  Channel 1   Channel 6

【干渉している状態（山が重なっている）】
     ▲▲▲
    /// \\\
   ///   \\\
──┴─────────┴──
  Channel 1 (混雑!)
```

- **2.4GHz帯のベストプラクティス**:
  2.4GHz帯は各チャンネルの帯域幅が重なり合っています。互いに干渉しにくい **1チャンネル、6チャンネル、11チャンネル** の使用が推奨されます。
- **5GHz帯のメリット**:
  チャンネル数が多く帯域が重ならないため、干渉に非常に強くなります。壁などの障害物が少ない場所では5GHz帯への切り替えが効果的です。

## ❓ トラブルシューティング（FAQ）

### Q1. 「Wi-Fiが見つからない / エラー」と表示される
- PCのWi-Fi（無線LAN）機能が有効になっているか確認してください。
- Windowsの「位置情報」サービスがOFFになっている場合、Wi-Fiスキャンが制限されることがあります。
- コマンドプロンプトを**「管理者として実行」**してアプリを起動してみてください。

### Q2. スキャンに少し時間がかかる
- Wi-Fiアダプターが周波数帯を順番にスキャンするため、数秒のウェイトが発生します。これは正常な動作です。

### Q3. 一部のWi-Fiが表示されない
- 信号強度フィルターのスライダーが右側に移動していないか確認し、「リセット」ボタンを押してください。
- 5GHz専用ルーター等の場合、「2.4GHz / 5GHz」の表示切替を試してください。
