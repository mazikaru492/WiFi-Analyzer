# Wi-Fi Environment Analyzer

## Wi-Fi電波を「見える化」するツール

**作成者**: 古家悠貴（25a31e0014）

---

## このアプリは何ができる？

周りに飛んでいるWi-Fi電波をスキャンして、**グラフで見える化**するアプリです！

**こんな人におすすめ：**

- 「なんかWi-Fiが遅い...」と困っている人
- どのチャンネルが空いているか知りたい人
- 自分のWi-Fiと他のWi-Fiがぶつかっていないか確認したい人

---

## 起動方法（2つのやり方）

### 方法1：EXEファイルで起動（かんたん！Python不要）

1. `dist` フォルダを開く
2. `WiFiAnalyzer.exe` をダブルクリック
3. アプリが起動する！

> **注意**: 初回起動時はWindowsのセキュリティ警告が出ることがあります。
> 「詳細情報」→「実行」をクリックしてください。

---

### 方法2：Pythonで起動（開発者向け）

#### 必要なもの

- Windows 10 または 11
- Python 3.8 以上

#### 手順

**ステップ1: 必要なライブラリをインストール**

コマンドプロンプト（またはPowerShell）を開いて、以下のコマンドを入力：

```
pip install pywifi comtypes pandas matplotlib
```

**ステップ2: アプリを起動**

このフォルダで以下のコマンドを実行：

```
python wifi_test.py
```

## 基本的な使い方

### ステップ1: アプリを起動する

アプリを起動すると、以下のような画面が表示されます。

```
┌──────────────────────────────────────────────────────────┐
│ 現在の接続: SSID [あなたのWi-Fi名] / IP [xxx.xxx.xxx.xxx] │
├──────────────────────────────────────────────────────────┤
│ [アダプター▼] [手動スキャン] [自動更新:OFF] ○2.4GHz ○5GHz │
├──────────────────────────────────────────────────────────┤
│                                                          │
│              ～ Wi-Fiスペクトラムグラフ ～                │
│                                                          │
├──────────────────────────────────────────────────────────┤
│ 検出ログ: スキャン結果がここに表示されます                 │
└──────────────────────────────────────────────────────────┘
```

### ステップ2: Wi-Fiをスキャンする

**「手動スキャン」ボタン**をクリック！

数秒待つと、周りのWi-Fiがグラフに表示されます。

### ステップ3: グラフを見る

- **横軸（X軸）**: チャンネル番号（1～14 または 36～165）
- **縦軸（Y軸）**: 電波の強さ（-100 ～ -20 dBm）
- **山の高さ**: 電波が強いほど山が高くなる
- **赤い山**: 今あなたが接続しているWi-Fi

### ステップ4: 詳細を確認する

グラフ上の**Wi-Fi名をクリック**すると、詳細情報が表示されます：

- SSID名
- 周波数帯（2.4GHz / 5GHz）
- チャンネル番号
- 信号強度
- 信号品質（優秀/良好/普通/弱い）

---

## ボタンの説明

| ボタン/操作          | 何ができる？                                         |
| -------------------- | ---------------------------------------------------- |
| **アダプター選択**   | 複数のWi-Fiアダプターがある場合に切り替え            |
| **手動スキャン**     | 1回だけWi-Fiをスキャン                               |
| **自動更新**         | ONにすると自動で繰り返しスキャン（リアルタイム監視） |
| **2.4GHz / 5GHz**    | 表示する周波数帯を切り替え                           |
| **グラフをクリック** | そのWi-Fiの詳細情報を表示                            |

## 電波の強さの見方

| 強度 (dBm)     | 状態       | 説明                     |
| -------------- | ---------- | ------------------------ |
| **-50 以上**   | 優秀       | とても良い！快適に使える |
| **-60 ～ -50** | 良好       | 問題なく使える           |
| **-70 ～ -60** | 普通       | 少し遅いかも             |
| **-80 ～ -70** | 弱い       | 不安定になりやすい       |
| **-80 未満**   | 非常に弱い | 接続が切れやすい         |

> **ポイント**: 数字が0に近いほど電波が強い！
> （-50 は -80 より強い）

## グラフの読み方のコツ

### 混雑しているチャンネルを見つける

グラフで**山が重なっている場所**は、電波が干渉している可能性があります。

```
良い状態（山が重なっていない）:
     ▲           ▲
    /  \        /  \
   /    \      /    \
──┴──────┴────┴──────┴──
  Ch1-3       Ch6-8

悪い状態（山が重なっている）:
     ▲▲▲
    /// \\\
   ///   \\\
──┴────────┴──
    Ch5-7 ← 混雑！
```

### おすすめの2.4GHzチャンネル

2.4GHz帯では、**チャンネル 1、6、11** が干渉しにくいです。

## うまく動かないとき

### 「Wi-Fiが見つからない」と表示される

- Wi-FiがONになっているか確認
- 機内モードがOFFになっているか確認
- アプリを**管理者として実行**してみる

### スキャンに時間がかかる

- Wi-Fiアダプターによっては、スキャン完了まで数秒かかることがあります
- これは正常な動作です

### グラフが表示されない

- 「2.4GHz」と「5GHz」を切り替えてみてください
- 一部のアダプターは片方の周波数帯しかスキャンできないことがあります
